## TECHNIQUE SELECTION GUIDELINES

**T1190 (Exploit Public-Facing Application):**
- Use for: HTTP/Web server exploitation
- Required anchor: `http_request_exploit`
- Server-side RCE (Apache, Tomcat, Nginx) = T1190, NOT T1203

**T1203 (Exploitation for Client Execution):**
- Use ONLY for: Memory corruption, buffer overflow, client-side exploits
- Required anchor: `memory_corruption`, `buffer_overflow`
- NEVER use for: Server-side RCE (use T1190 instead)
- NEVER use `process_creation` as T1203 anchor

**T1059 (Command and Scripting Interpreter):**
- Use for: Post-exploitation shell spawn, command execution
- Required anchor: `shell_spawned`, `process_creation`

**T1071 (Application Layer Protocol):**
- Use for: Callbacks, C2 channels
- Required anchor: `network_callback`, `http_callback`, `ldap_callback`, `outbound_ldap_callback`

**T1105 (Ingress Tool Transfer):**
- Use for: File/tool downloads
- Required anchor: `tool_download`, `file_downloaded`, `file_written`

**T1068 (Exploitation for Privilege Escalation):**
- Use for: Kernel exploits, driver vulnerabilities, service privesc
- Required anchor: `privilege_escalation`, `privilege_escalation_exploit`, `local_privilege_escalation`
- NOT for: Generic config modification

**T1505.003 (Server Software Component - Web Shell):**
- Use ONLY when: Phase 1 has `webshell_drop` OR explicit persistence via upload
- Required anchor: `webshell_drop` (EXACT MATCH)
- NOT for: Generic file upload without persistence intent

**T1556 (Modify Authentication Process):**
- Use for: Authentication bypass, cryptographic flaws, identity spoofing
- Required anchor: `authentication_bypass`, `cryptographic_flaw`, `identity_spoofing`
- Sub-techniques:
  - T1556.002 (NTLM) - Zerologon, Netlogon
  - T1556.003 (Kerberos) - Golden/Silver tickets
  - T1556.001 (PAM) - Unix/Linux PAM
  - T1556.004 (Credential Manager) - Windows

**T1078 (Valid Accounts):**
- Use ONLY if Phase 1 explicitly states attacker obtains/uses valid account
- NOT the same as authentication bypass

**T1003 (OS Credential Dumping):**
- Use for: Post-exploitation credential extraction
- Required anchor: `credential_dumping`
- Sub-techniques:
  - T1003.001 (LSASS)
  - T1003.002 (SAM)
  - T1003.003 (NTDS)
  - T1003.008 (/etc/shadow)

**T1486 (Data Encrypted for Impact):**
- Use for: Ransomware
- Required anchor: `ransomware_behavior`, `encryption`

**T1499.004 (Endpoint DoS):**
- Use for: Service crash, DoS
- Required anchor: `dos_observed`, `service_crash`
